## How to Add Credits

When you download images:

1. Note the photographer's name
2. Copy the photo URL
3. Update this file with complete information
4. Update the [Photographer Name] placeholders above

Example format:
```
**filename.jpg**
- Source: Unsplash
- Photographer: John Doe
- URL: https://unsplash.com/photos/abc123xyz
- License: Unsplash License
- Usage: Homepage hero background
```
